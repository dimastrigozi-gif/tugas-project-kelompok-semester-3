# Turnamen Esport — Sistem Informasi dan Tata Kelola Turnamen

Aplikasi web untuk mengelola turnamen esport dengan tiga aktor: peserta, penyelenggara, dan super admin.

**Stack:** Laravel 13 • Livewire 4 • MariaDB • Redis

---

## Prasyarat

- PHP 8.3+ (ekstensi: pdo_mysql, redis, mbstring, openssl, ctype, curl, fileinfo, xml, tokenizer)
- Composer 2.x
- Node.js 20+ & npm
- MariaDB 10.6+
- Redis 7.x
- Git
